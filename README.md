# Imperium Maledictum українською

Довідник для ваших пригод у похмурому 41-му тисячолітті. Правила, спорядження та здібності персонажів — українською, з англійськими назвами для швидкого звірення з книгами.

## Що всередині

- **Персонаж:** 139 талантів, навички та калькулятор покращень характеристик. У «Докладніше» можна перемикатися між повним українським описом та англійським оригіналом.
- **Спорядження й бій:** зброя, броня, аугметика, дії, стани, рани та травми.
- **Псайкерство та світ:** сили, небезпеки Варпу, послуги й таблиця імен.
- Пошук обома мовами, світла й темна теми та зручний перегляд на телефоні.

## Як відкрити

Завантажте проєкт і відкрийте **index.html** у браузері. Усі десять HTML-сторінок мають лежати поруч. Для користування встановлювати нічого не потрібно.

Для nginx скопіюйте готові HTML, `README.md`, `MAINTAINING.md`, `NOTICE.md`, `LICENSE` та папку `licenses/` у каталог сайту, наприклад `/var/www/talents`.

## Для тих, хто хоче долучитися

Помітили помилку в перекладі чи маєте ідею? Створюйте Pull Request у цьому репозиторії. Інструкції зі збірки та перевірки — у [MAINTAINING.md](MAINTAINING.md).
